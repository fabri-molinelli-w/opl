## Prompt

> Leé AGENTS.md, Makefile, backend/go.mod, frontend/package.json, frontend/.nvmrc y docs/roadmap.md.

> Tarea: paso 0.7 del roadmap. CI con GitHub Actions.

> Alcance:
> 1. .github/workflows/ci.yml que corra en push y pull_request a main, con tres jobs en paralelo:
>    - backend: Go según backend/go.mod (con cache), go vet, golangci-lint (action oficial), go test.
>    - frontend: Node según frontend/.nvmrc (con cache de npm), npm ci, lint, typecheck, test, build.
>    - contract: instala oapi-codegen v2.8.0 y sqlc v1.31.1 (versiones fijas, las mismas que uso local),
>      npm ci en frontend, corre make generate y falla si `git diff --exit-code` detecta cambios.
>      Así el CI detecta código generado desactualizado respecto de api/openapi.yaml.
> 2. Target "check-generated" en el Makefile que haga lo mismo que el job contract, para poder correrlo local.
> 3. Badge del CI en el README.
>
> Reglas:
> - Acciones con versión mayor fija (actions/checkout@vN, etc.). Consultá con context7 o la documentación
>   oficial cuáles son las versiones mayores actuales; no las supongas.
> - No se necesitan secretos ni base de datos: si algún test requiere Postgres, avisame en lugar de agregar un servicio.
> - En el Makefile solo agregá; no modifiques los targets existentes.
>
> No escribas código. Entregá el contenido propuesto de ci.yml, el target nuevo del Makefile y cómo verificarlo.

> (Build) Implementá el plan aprobado. Corré make verify y make check-generated localmente y corregí hasta que pasen.

## Resultado

- `.github/workflows/ci.yml` nuevo, con 3 jobs paralelos (`backend`, `frontend`, `contract`) en push/PR a `main`.
  Acciones con mayor fija: `actions/checkout@v7`, `actions/setup-go@v7`, `actions/setup-node@v7` y
  `golangci/golangci-lint-action@v9` (golangci-lint v2.15.0). Sin secretos ni base de datos.
- `Makefile`: target `check-generated` agregado al final (instala oapi-codegen v2.8.0 y sqlc v1.31.1,
  corre `make generate` y `git diff --exit-code`). Los targets existentes no se tocaron.
- `README.md`: badge de CI debajo del título.
- `docs/roadmap.md`: paso 0.7 marcado ✅.
- Iteraciones del loop de autocorrección: 0. `make verify` verde a la primera; `make check-generated`
  exit 0 sin diff; extra `npm run build` (cubre lo que `make verify` no incluye) verde.

## Aprendizaje

- Las versiones mayores actuales no se suponen: se confirmaron contra los releases oficiales vía el MCP
  `github` (checkout v7, setup-go v7, setup-node v7, golangci-lint-action v9). `mypy`/memoria habrían
  quedado desactualizadas.
- El test de backend usa un `fakePinger` y el de frontend Vitest+jsdom: ningún job necesita Postgres.
- `golangci-lint-action` corre con `node24` y no respeta `defaults.run.working-directory`; hay que pasarle
  `working-directory: backend` explícito.
- Para verificar `make check-generated` en local con cambios sin commitear, conviene dejar esos cambios en
  el índice (`git add -A`) para que el `git diff --exit-code` del target refleje solo lo generado.
